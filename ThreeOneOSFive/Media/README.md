# App video assets

Upload these two files into this exact folder (`ThreeOneOSFive/Media/`) using the exact filenames:

- `Keyauthvideo.mp4` — License/Auth full-screen background video (no banner).
- `Functionscreen.mov` — Functions screen banner video and the app-wide looping audio source.

Do not rename either file or change the extensions. The Xcode project is configured to bundle both files from this folder.
